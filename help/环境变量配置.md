.env为开发环境变量，不需要提交到git

在项目根目录创建：.env（本地开发用，加入 .gitignore）
在代码里用 pydantic-settings 定义 Settings，自动从环境变量/.env 读取
生产环境不放 .env，直接由部署环境注入环境变量


pydantic-settings 的加载优先级

系统环境变量（export 出来的那些）
.env 文件（你 model_config 里指定的 env_file）
类属性默认值（"change-me"）

docker run --env-file（用文件注入）
docker run --rm -p 9999:9999 \
  --env-file .env \
  your-image:tag


如果你有/要加 docker-compose.yml，可以这样写（两种写法二选一或都用）：
services:
  api:
    image: your-image:tag
    ports:
      - "9999:9999"
    env_file:
      - .env
